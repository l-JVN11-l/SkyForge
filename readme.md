# hackPHS 2026: Into the Skies

### SkyForge: Built on Earth. Engineered for the Sky.

Developed for "Into the Skies" at HackPHS, this project is an interactive mini turret built using Arduino,  custom 3D-printed bases, and multiple motors, all connected through jumper wires. Programmed inside VS Code, the system pairs a stepper motor for continuous left-and-right base rotation with a servo motor to adjust the vertical tilt of the launching arm. It features an advanced, proportional arcade-style control scheme mapped directly to an Xbox controller: the left joystick drives the firing mechanism, the right joystick pans the base, the X button fires ball-like projectiles into the air, and the B button instantly triggers a safety reset back to the turret's default home position (0° stepper, 90° servo). Additionally, this also incorporates a proportional velocity controller allowing faster movement on the joysticks to translate to translate to faster motor movement. From activity on the x-box, to Python, to C++ in Arduino, connected to the Arduino itself and the breadboard, all the way to the two motors, this project acts not only can be used for tracking weather paterns, launching satellites in charge of GPS, and as a weapon for both tracking airborne targets as well as firing back, this project bridges the gap between consumer gaming hardware and high-precision robotics out of an everyday Xbox controller and a budget Arduino microcontroller.
